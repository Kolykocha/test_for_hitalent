# Department Management API

API для управления подразделениями и сотрудниками с поддержкой древовидной структуры.

## 📋 Описание проекта

Проект представляет собой REST API для управления иерархической структурой подразделений компании и сотрудниками. Поддерживает создание, обновление, удаление и получение подразделений с вложенными сотрудниками.

### Основные возможности

- **Управление подразделениями**: создание, обновление, удаление, получение дерева подразделений
- **Управление сотрудниками**: создание сотрудников в подразделениях
- **Древовидная структура**: поддержка вложенных подразделений с ограничением глубины (1-5 уровней)
- **Каскадное удаление**: удаление подразделения со всеми сотрудниками и дочерними подразделениями
- **Перемещение сотрудников**: при удалении подразделения можно переместить сотрудников в другое подразделение
- **Автоматические миграции**: Alembic для управления схемой БД
- **Docker контейнеризация**: легкий запуск через docker-compose

## 🛠 Технологии

- **Python 3.11** - язык программирования
- **FastAPI** - веб-фреймворк
- **SQLAlchemy** - ORM
- **PostgreSQL** - база данных
- **Alembic** - миграции
- **Docker & Docker Compose** - контейнеризация
- **Uvicorn** - ASGI сервер

## 🚀 Быстрый запуск

### Требования

- Docker и Docker Compose установлены
- Git (для клонирования репозитория)

### Запуск с Docker

1. **Клонируйте репозиторий:**
#bash
git clone <repository-url>
cd test_for_hitalent/backend

2. **Запустите приложение:**
#bash
docker-compose up --build

3. **Дождитесь запуска (первые 10-20 секунд могут создаваться миграции)**

4. **Откройте в браузере:**

API документация: http://localhost:8000/docs

ReDoc документация: http://localhost:8000/redoc

Health check: http://localhost:8000/health


Остановка приложения
bash
# Остановить контейнеры
docker-compose down

# Остановить и удалить данные БД
docker-compose down -v
